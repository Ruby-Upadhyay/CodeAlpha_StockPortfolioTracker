# Stock Portfolio Tracker

A Python-based Stock Portfolio Tracker developed as part of the **CodeAlpha Python Programming Internship**.

## Project Overview

This project is a menu-driven Stock Portfolio Tracker that allows users to manage their stock holdings, calculate investment values, record transactions, and view portfolio statistics.

The program uses predefined stock prices and stores portfolio and transaction information in text files.

## Features

* View available stocks and their prices
* Add stocks to the portfolio
* View current portfolio
* Remove a stock completely
* Sell selected shares
* View transaction history
* View portfolio statistics
* Save portfolio data to a text file
* Load previously saved portfolio data
* Record transaction date and time
* Handle invalid inputs and errors

## How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Open the Project

Open the project folder in VS Code.

### 3. Open the Terminal

Open the VS Code terminal and navigate to the project folder.

### 4. Run the Program

```bash
python stock_portfolio.py
```

## Menu Options

The program provides the following options:

1. Available Stocks
2. Add Stock
3. View Portfolio
4. Remove Stock
5. Sell Shares
6. Transaction History
7. Portfolio Statistics
8. Exit

## Data Storage

The program uses two text files to store data:

* `portfolio.txt` — Stores the current stocks and quantities in the portfolio.
* `transactions.txt` — Stores the complete transaction history with date, time, stock, quantity, price, and total value.

These files are included in the repository as sample output files and are updated automatically when the program runs.
